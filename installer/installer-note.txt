NPV Tunnel — what the installer does
====================================

1. Copies the application into your own profile (%LOCALAPPDATA%\Programs\NPV
  Tunnel). No administrator rights, no UAC prompt.

2. Registers the .npvt file association for the current user only. After Setup
  finishes you can double-click a .npvt file anywhere - Explorer, a download
  window, a chat attachment - and it is imported into the app immediately, the
  same way an APK import works on Android.

3. Optionally adds a Start menu entry and a desktop shortcut.

Nothing else is touched. No service is installed, no scheduled task is created,
no firewall rule is added, and the Windows proxy setting is only changed while
a tunnel is actually connected — and restored when it disconnects.

Uninstalling removes the app and the association. Your saved configurations stay
in %APPDATA%\NpvTunnel until you delete that folder yourself.

The tunnel engine (Xray-core, MPL-2.0) ships inside this package, so the first
connection works offline — nothing is downloaded at install time.
