Layout parity with the phone

This mirrors the WPF window in 1.1.0: same order, same glyphs, same spacing rhythm as the Android screenshots.

PALETTE

Dark is the default because that is the phone's design. Warm light replaces it with cream paper (#F5EFE3 → #FBF6EC) and brown-black ink (#2B2721): the accents are the same emerald and teal, darkened so they hold their contrast on paper. Nothing in that palette is pure white, which is the whole point of it.

BUTTONS

One template owns the hit area (32 px minimum), the corner, the focus ring and the disabled state. Hover and press swap the fill instead of fading the control, so the label stays readable.

WHAT CHANGED

Sidebar gone. A centred wordmark and version, the amber badge button at the top right, the floating action pill above the nav, and the four-item bottom navigation with a pill under the active tab.

CONFIGS

Last ping / Ping, Smart Route, the Saved group with its collapsible list, a pinned row outlined in mint, and Global Network with the teal-to-mint session bar. Search lives in the pill, not in the page.

IMPORT

.npvt containers from channels open now: the vendor's white-box AES-CTR blocks are decoded in-process and every profile inside is imported at once — the panel above shows two of them already listed under Saved.

HONEST DIFFERENCES

A desktop window needs window controls, so there is a drag strip with minimise / maximise / close. There is no phone status bar, and rows size to the window height instead of a fixed 6-inch viewport.
