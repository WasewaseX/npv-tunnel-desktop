ROUTING & LEAK PROTECTION

Set the Windows system proxy while connected
Block IPv6 inside the tunnel

Send local network traffic direct
Block BitTorrent

DNS resolver
Queries go through the tunnel as DNS-over-HTTPS.
https+local://1.1.1.1/dns-query
Allow invalid TLS certificates (not recommended)
Imported configs can never enable this by themselves. Turning it on lets a network attacker impersonate your server.
